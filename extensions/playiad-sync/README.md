# Mandat OS — Extension Chrome Playiad Sync

Cette extension Chrome officielle vous permet d'importer directement vos leads acquéreurs depuis votre espace **Playiad / iad France** vers votre CRM **Mandat OS** en 1 clic.

---

## 🚀 Installation rapide dans Chrome (10 secondes)

1. Ouvrez **Google Chrome** et allez sur `chrome://extensions/`
2. Activez le **Mode développeur** (interrupteur en haut à droite).
3. Cliquez sur **"Charger l'extension non empaquetée"** (Load unpacked).
4. Sélectionnez le dossier : `extensions/playiad-sync/`.

---

## ⚡ Utilisation

1. Connectez-vous à votre intranet **Playiad / iad France**.
2. Allez sur votre page de liste des **Leads Acquéreurs**.
3. Un bouton bleu **⚡ Synchroniser avec Mandat OS** apparaît en bas à droite de votre écran.
4. Cliquez dessus : tous vos acheteurs sont immédiatement importés et dédupliqués dans Mandat OS !
